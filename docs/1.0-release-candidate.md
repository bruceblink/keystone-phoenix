## 版本配套

- 标准生产组合为 `admin-web v1.0.0 + Native v1.0.0`。
- `admin-web v1.0.0 + Phoenix v1.0.0` 是可替换组合。启用前需要在目标环境重新完成接口、权限、业务错误码、登录、通知、查询、写操作和响应式布局验收。
- Phoenix 1.0 发布包含 JSON API 和 LiveView 管理页面。LiveView 页面以 admin-web 的页面结构、布局、文案、交互和响应式行为为基准。
- Native 1.0 发布后进入维护阶段，只修复缺陷、安全问题和依赖兼容问题。新增业务功能主要进入 Phoenix 主线。

## 外部环境边界

以下检查需要目标环境、真实身份提供商或真实硬件，不能由本地测试和 GitHub Actions 替代：公网 OIDC、浏览器或硬件 Passkey 仪式、真实生产 CSRF/Cookie、生产多节点恢复、生产 TLS/反向代理链、生产数据恢复和发布窗口检查。它们属于 1.0 发布后的部署验收记录。
