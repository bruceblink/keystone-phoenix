# Keystone Phoenix 重写计划

## 目标

将原 Keystone 的本地账号、系统管理、监控和任务管理能力迁移到 Phoenix、Ecto、PostgreSQL、Redis 和 LiveView。迁移保留现有 JSON 响应结构、路径、字段名和认证语义。每个模块先完成数据库资源、领域查询与命令、HTTP 控制器、认证边界和测试，再接入 LiveView 页面。

执行分为两个阶段。第一阶段完成 Keystone 功能重写，优先保证接口、数据和认证行为兼容现有 `bruceblink/keystone-frontend`。第二阶段在功能迁移完成后，再处理 Elixir 运行时的内存、并发、缓存和部署优化。

## 当前基线

已完成健康检查、字典类型与数据、系统配置、用户查询、RSA 登录密码解密、RS256 access/refresh token、单账号会话控制、登录 LiveView 和管理员概览。最近的用户管理切片还包括用户新增、更新、软删除、重置密码和状态变更。

## 执行顺序

1. **组织与权限基础**：部门、岗位、角色、菜单、角色菜单关联。已完成表、种子数据、列表、详情、树形下拉、部门、岗位、角色和菜单写命令、角色授权读取、角色用户分配查询和登录后的菜单数据。
2. **用户关联完善**：已完成个人资料、修改密码、管理员权限边界、用户关联 ID 校验和头像文件存储。
3. **公告与日志**：已完成公告 CRUD、登录日志和操作日志查询/清理、认证用户主动写入操作日志、登录结果自动记录，以及管理写操作自动审计和敏感参数脱敏。
4. **登录入口**：已完成 `/getConfig`、Redis 一次性验证码生成与校验、`/captchaImage` 和明确的 `/register` 未支持响应；开放注册仍保持关闭，等第一阶段接口兼容完成后再决定是否引入策略。
5. **监控与在线会话**：已完成在线用户查询、强制下线、Redis 缓存状态、BEAM 主机运行信息和网络状态 SSE 快照。
6. **定时任务**：已完成任务定义和任务日志 CRUD、调用目标列表、启停、立即执行、动态 Cron 调度、并发控制、超时取消和失败记录；第二阶段已降低轮询频率并增加任务并发上限配置。
7. **LiveView 管理页面**：已完成登录、管理员概览、部门、角色、菜单、公告、用户、配置、字典、定时任务、监控和日志面板；第一阶段管理页面迁移完成，后续只补充与 API 能力同步的交互。
8. **运行与部署优化**：已完成调度并发限制、角色统计聚合查询、生产 release 迁移命令、Docker 多阶段构建和 PostgreSQL/Redis 就绪探针。

## 每个切片的验收条件

- PostgreSQL 迁移可重复执行，字段和原 API 契约一致。
- 未登录请求返回现有 `40101` 响应；需要管理员的请求对普通用户返回 `40301`。
- 领域层负责输入校验、事务、软删除和缓存失效；控制器只做参数分派和响应映射。
- 密码、令牌和其他敏感字段不出现在响应、日志或持久化明文中。
- 为新增行为添加针对真实实现的单元或数据库测试，并运行格式、编译、测试和集成检查。
- 需要真实窗口的 LiveView 改动使用 Computer Use 验收；无可用窗口时记录限制，不把 headless 结果当作真实窗口证据。

## 验证命令

```powershell
docker compose up -d postgres redis
mix format --check-formatted
mix test
mix precommit
```

当前工作站已配置 `mix`、Elixir、Erlang/OTP 和 WSL Docker。数据库集成测试仍需要稳定运行 PostgreSQL 与 Redis 容器；容器未保持运行时，不把编译结果当作数据库测试通过证据。

## 回滚边界

每个模块使用独立提交。数据库迁移只追加，不修改已共享迁移；回滚通过反向迁移或恢复对应模块提交完成。未完成模块不进入已完成模块的提交。
